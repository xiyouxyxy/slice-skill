# slice — 切片计划 Skill

把一个「大目标 / 课程提纲 / 长期任务」自动切成「每天可执行」的计划，并支持每日打卡、落后自动重排、导出日历。

适用场景：
- **目标型**：给我一个大目标 → 拆成每日计划；你可输入每天投入时长，也可不输入、让 skill 按截止日反推节奏。
- **课程型**：给我课程提纲 + 预计完成时间 → 拆成每天看多少内容 + 间隔复习（+1 / +3 / +7 天）。
- **任何目标原型**：考雅思拿 7.5 / 有素描基础学丙烯画 / 有前端基础学 Python / 写一本书 / 每天冥想——skill 先判定目标原型（应试 / 编程 / 技能 / 知识 / 项目 / 习惯），按原型生成对应的话术、验收手段与复习策略，而不是一套模板通吃。
- **通用长期任务型**：不限学习，任何长期任务都能切，重点是「可计划、不拖延」。

## 特性
- **目标原型自适应（archetype）**：先判原型——应试 `exam` / 编程 `coding` / 技能 `skill` / 知识 `knowledge` / 项目 `project` / 习惯 `habit`，引擎按原型分派话术与验收手段：应试型验收是模考分数、复习是**轮做制**（短间隔复盘错题 + 换新题；间隔 ≥30 天后二刷真题，对比首刷找出仍错的题）；编程型是能跑通的代码；技能型是作品留证对比；习惯型保 streak
- **排程双向适配**：时间不够 → 合并任务并预警「时间紧」；时间太多（如「雅思 15 个任务 vs 考试前 95 天」）→ **自动铺满到截止日**——应试型插入模考节点（考前 30/14/7 天固定日期）、追加间隔复习轮次，剩余空档作消化间隔，并在计划里写明补了什么
- **每日预算校验**：单任务时长超过每日投入预算即预警，提示拆分或提高投入
- 统一目标卡片：描述 / 类型 / 原型 / 截止日 / 每日时长(可选) / 可用日 / 优先级
- **完成标准三件套**：每个原子任务都带「**子目标**（2–4 条可勾选能力点）/ **验收**（题/产出/动作）/ **口述自检**」——**口述题由规划 LLM 根据当天内容现生成 1–3 道具体对比/解释题**（命中最易混、最反直觉的点，而非泛泛而谈），把"模糊概念"变成"具体可验证的完成标准"，三件套全勾才算 ✅
- **入口前置条件问询**（按「是否需要专用器材 / 材料」判定，而非按类型）：需要器材的动手技能型（画画 / 乐器 / 烹饪 / 运动）**即便归为学习也必问**——没颜料就练不了；纯知识 / 理论型可选。缺的项排成前几个 setup 里程碑（装环境 / 注册账号 / 申请权限 / 下数据集），行政类长周期依赖第 1 周就发起，避免中后期卡壳。可留空，用户后续补充时再回写计划。
- 双向排程：有截止日→反推每日负荷；无时长无截止日→默认节奏（不追问）
- 工作分解：里程碑 → 25–50 分钟原子任务；「部分迁移」提示（有素描基础 ≠ 会色彩，只对可迁移的部分做跳过 / 压缩）
- 间隔复习：新内容后 +1 / +3 / +7 天自动排复习；复习卡带「复习指向」动态列回原始任务 / 里程碑（非写死）
- 缓冲与拖延防御：缓冲日**不打断里程碑内部连续任务**（保护「铺色 → 等干 → 刻画」这类流程）+ 最小可执行单元 + 落后自动重排
- 每日打卡提醒：到点提醒、回报完成度、自动重排
- **状态源统一**：`.md` 计划文件是唯一真源；HTML 勾选是本机离线副本（版本号机制自动覆盖过期勾选），「导出回写指令」JSON 可交给 AI 写回 `.md` 正式生效
- 导出（规划后**用户自选格式**）：Markdown / `.ics` 日历 / HTML 网页（三件套子项作为可勾选框；口述自检每项附可编辑文本框存口述答案；勾选状态本机持久化，可导出回写 `.md`）/ 纯清单

## 安装

仓库本身就是一个**跨 agent 通用**的「切片计划」skill（不绑定任何特定产品）。**核心内容就一份**：`SKILL.md` + `references/` + `scripts/`，按你使用的 agent 复制到对应的加载位置即可：

| Agent | 安装方式 |
|-------|---------|
| **通用（任何读 markdown skill 的 agent）** | 把 `SKILL.md` + `references/` + `scripts/` 整体复制到该 agent 的 skills 加载目录 |
| **Claude Code** | 复制到 `~/.claude/skills/slice/`（全局）或 `<项目>/.claude/skills/slice/`（项目级），重启 Claude Code |
| **Codex** | 把 `SKILL.md` 的正文**追加**到 `~/.codex/AGENTS.md` 或项目根 `AGENTS.md`（Codex 没有 skill 目录机制，按指令文件读取） |

安装后，在对话中说「帮我把 X 切成每天计划」「把这门课排进日程（X 月 X 日前学完）」即可触发。

> 计划文件默认落在 `<workspace>/.slice/plans/<goal-slug>.md`，可改为任意你喜欢的路径。

## 用法示例
- 目标型：`/slice 三个月学会 Python 做数据分析`（不填每日时长 → 按 3 个月窗口反推）
- 课程型：`/slice-course 提纲... 截止 2026-11-01`
- 自然语言：「帮我把写书的计划切成每天该做什么」

## 导出（规划后由用户选择格式）

规划完成后，skill 会主动询问你要哪种导出格式，**默认推荐 Markdown**，不会一股脑只吐 `.ics`：

| 格式 | 命令 / 产物 | 适合谁 | 怎么打开 |
|------|------------|--------|----------|
| **① Markdown（默认）** | 计划本身就是 `.md` 文件 | 所有人；最通用 | 记事本 / VS Code / 任意文本编辑器 |
| **② HTML 网页** | `export_html.py` → `xxx.html` | 想双击即看、带勾选框、可打印 | **浏览器直接双击打开**，无需装任何软件；勾选状态自动存本机（localStorage），关掉再打开仍在，并能导出/导入进度 JSON 备份 |
| **③ .ics 日历** | `export_ics.py` → `xxx.ics` | 要导入手机/桌面日历、每天弹提醒 | 日历 App（苹果日历 / Google 日历 / Outlook）导入 |
| **④ 纯清单** | 计划文件里的勾选表 | 想手抄 / 贴到别处 | 同 Markdown |

脚本调用（全部仅依赖 Python 标准库）：
```
# 1) 规划引擎：LLM 做完 WBS 的 spec JSON → 计划 .md（自动排程/缓冲/间隔复习）
python scripts/generate_plan.py build --in spec.json --out plans/xxx.md [--start 2026-09-05]

# 2) .md → events JSON（导出前置步骤，.md 是唯一真源，不必手写第二份 JSON）
python scripts/plan_to_events.py --in plans/xxx.md --out plans/xxx-events.json

# 3a) HTML 网页（带勾选框，浏览器打开）；3b) .ics 日历（导入手机日历）
python scripts/export_html.py --in plans/xxx-events.json --out xxx.html --name "我的计划"
python scripts/export_ics.py  --in plans/xxx-events.json --out xxx.ics

# 落后自动重排（Step 9.2）：把未完成且已过期的任务顺延到最近可用日
python scripts/generate_plan.py reschedule --in plans/xxx.md --today 2026-09-20 \
    --done 2026-09-05,2026-09-06 --out plans/xxx-resched.md
```

> 推荐给电脑端用户的路径：选 **Markdown 或 HTML** 即可，无需折腾日历 App。

## 文件结构
```
slice/
├── SKILL.md              # skill 工作流与触发规则（AI 读取后照做）
├── references/
│   ├── plan-template.md  # 计划文件标准格式
│   └── examples.md       # 四类场景完整示例（学习 / 课程 / 项目 / 习惯）
└── scripts/
    ├── generate_plan.py  # 规划引擎：spec JSON → 计划 .md（build）+ 落后重排（reschedule）
    ├── plan_to_events.py # 计划 .md → events JSON（导出链路前置解析，.md 为唯一真源）
    ├── export_ics.py     # events JSON → .ics 日历导出
    └── export_html.py    # events JSON → HTML 网页（带勾选框、可打印）
```

> 说明：**整条链路已确定性化**——`generate_plan.py` 负责按文档 Step 5/6/7 把 spec 渲染成 `.md`（排程、缓冲、+1/+3/+7 间隔复习、可用日过滤全由脚本算），`plan_to_events.py` → `export_*.py` 负责导出，重排由 `generate_plan.py reschedule` 完成。WBS（定里程碑/任务/三件套）仍是 LLM 的语义活，由 spec JSON 输入引擎。
